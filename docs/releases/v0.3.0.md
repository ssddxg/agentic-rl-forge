# AgenticRLForge 0.3.0

The first public alpha release of **AgenticRLForge**: a local-first workbench for building,
inspecting, evaluating, and exporting reinforcement-learning data for search and tool-using
agents.

## Why try it

- **See a real agent trajectory.** Run a search-agent loop in the browser and inspect actions,
  observations, token masks, reward components, and the final outcome.
- **Exercise the full data path on a laptop.** Use bundled or custom QA/corpus JSONL data to run
  grouped rollouts, persistence, evaluation, learning-signal filtering, and verified trainer-batch
  export without a GPU.
- **Move toward real training.** Reuse Search-R1, GRPO, verl export, PRM-guided MCTS, rejection
  sampling, Nash-MD, hindsight relabeling, experiment, and promotion utilities.
- **Stay local by default.** Core workflows require no account or API key and send no usage
  telemetry. An auxiliary private-document workspace supports local multilingual retrieval.

## Start in one command

Run the published container and open <http://127.0.0.1:7860>:

```bash
docker run --rm \
  -p 127.0.0.1:7860:7860 \
  -v agentic-rl-forge-data:/app/data \
  ghcr.io/ssddxg/agentic-rl-forge:0.3.0
```

Or install the attached wheel directly from this release:

```bash
python -m pip install \
  "agentic-rl-forge[studio] @ https://github.com/ssddxg/agentic-rl-forge/releases/download/v0.3.0/agentic_rl_forge-0.3.0-py3-none-any.whl"
arf doctor --profile core --strict
arf studio
```

Windows users can also download the source archive, extract it, and double-click
`Start AgenticRLForge.cmd`.

## Included in 0.3.0

- Local Studio with runtime diagnostics, trajectory inspection, dataset upload, background
  offline-pipeline runs, persistent history, and interruption recovery.
- Safe PDF, DOCX, HTML, Markdown, RST, and text ingestion with multilingual BM25 search and
  optional cited OpenAI-compatible answers.
- Typed multi-turn environments, Search-R1-compatible collection, grouped GRPO utilities,
  policy-version guards, evaluation, trainer-batch export, and experiment tooling.
- Content-verified SQLite/sharded storage, deterministic manifests, signed archives, resumable
  artifact transport, promotion workflows, and release auditing.
- Tested Python 3.10-3.12 support, wheel smoke tests on Linux/Windows/macOS, container acceptance
  tests, strict typing, linting, coverage, and dependency auditing.

## Release assets and trust

This release contains a wheel, source distribution, SHA-256 checksum manifest, and the generated
release-audit evidence. The same source is published as versioned and `latest` images in GitHub
Container Registry.

AgenticRLForge is an alpha release. CPU data-generation and validation workflows are usable on an
ordinary computer; updating model weights still requires an external GPU training environment,
PyTorch, model services, and verl.
